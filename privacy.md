# Privacy — lunaris-Auto

Last updated: 22 September 2026

lunaris-Auto runs only in your browser. It does not collect, store, or send personal data to us.

## What it does locally

- Shows an overlay on quest pages
- Reads quest progress already available in the page
- Optionally adjusts the User-Agent on matching hosts so desktop-style quest tasks can run in the browser
- Stores two preferences on the device: auto-ignite on/off, and pace (swift or calm)

## What it does not do

- No accounts, analytics, ads, or crash telemetry
- No off-device storage of quest names, IDs, or progress
- No extra network calls beyond the host you already use

## Permissions

Used only to inject the overlay, apply header tweaks on the matching host, and remember local preferences.

Uninstall from the browser’s extension page at any time.
